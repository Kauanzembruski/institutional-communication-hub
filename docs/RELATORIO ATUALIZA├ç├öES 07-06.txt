2. Módulo de Cardápio
Foi realizada uma revisão completa do fluxo de gerenciamento do cardápio semanal, simplificando a operação e reduzindo possíveis inconsistências.

Alterações nas Views
Simplificação da Estrutura
Foi removida a lógica de criação dinâmica de registros de cardápio.
Novo Fluxo
O sistema passou a trabalhar apenas com atualização dos registros existentes.
Tratamento de Campos Vazios
Foi implementada uma regra para preenchimento automático quando o campo de lanche for enviado vazio.
Comportamento:
Campo vazio → "-"
Isso garante que a exibição pública nunca apresente campos em branco.
Atualização da Interface
Ajustes realizados nas respostas das requisições AJAX para atualização imediata da tabela sem necessidade de recarregar a página.

Alterações nas URLs
Rotas Removidas
Foi removida a rota responsável pela criação de novos registros de cardápio.
Rotas Mantidas
Visualização do cardápio.
Edição dos registros existentes.

Benefícios Obtidos
Maior controle sobre os dias exibidos.
Redução da complexidade da interface administrativa.
Prevenção de inconsistências causadas pela criação ou exclusão de dias da semana.
Melhor experiência para os usuários responsáveis pela manutenção do cardápio.
Padronização dos dados exibidos na tela pública.

11. Módulo de Eventos

Banco de Dados
alteração da Tabela eventos
Foi alterada a tabela responsável por armazenar os registros de eventos.
CREATE TABLE eventos (

    id_evento SERIAL PRIMARY KEY,

    titulo VARCHAR(150) NOT NULL,

    descricao TEXT NOT NULL,

    data_inicio DATE NOT NULL,

    data_fim DATE NOT NULL,

    hora_inicio TIME NOT NULL,

    hora_fim TIME NOT NULL,

    imagem VARCHAR(255),


    data_criacao TIMESTAMP DEFAULT CURRENT_TIMESTAMP

);
